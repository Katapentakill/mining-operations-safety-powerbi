Límites reales (qué no se podría igual)

● LímiteAnimación entre estados

Power BI cambia de estado sin transición. Aquí hay un fundido suave que allá no existirá.

● LímiteBarra superior con pestañas

Se arma con botones o el navegador de páginas horizontal; no tiene el resaltado animado de este prototipo.

● LímiteMapa estilizado

Aquí el mapa es un dibujo gris para no depender de internet. En Power BI sería el mapa de Bing en estilo claro.

● LímiteTooltip personalizado

Aquí cada gráfico tiene uno a medida. En Power BI sería el tooltip por defecto con 3 datos (los de página no funcionaron en tu Desktop).
